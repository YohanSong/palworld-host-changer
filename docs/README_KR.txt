친구들끼리 멀티(co-op, 초대 코드) 하다가
"호스트를 다른 사람으로 바꾸고 싶다" / "친구가 서버를 못 열어준다"
"호스트 바꿨더니 내 캐릭/팰/맵이 날아갔다" 를 해결하는 도구다.

설치 필요 없음. 공식 파이썬 런타임이 폴더에 같이 들어있다(파이썬 따로 설치 X).
※ zip 안에서 바로 실행하지 말고, 반드시 압축을 푼 뒤 실행할 것.
무료 / 오픈소스(GPL-3.0). 비공식 팬 도구이며 Pocketpair와 무관.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 먼저 알아야 할 팰월드 co-op 구조
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1) 세이브 위치
   %LOCALAPPDATA%\Pal\Saved\SaveGames\(숫자 폴더)\(32자리 월드ID)\
     Level.sav       ← 월드 전체(모든 캐릭터·팰·거점·길드). 진짜 알맹이.
     LevelMeta.sav   ← 월드 선택창에 뜨는 이름/레벨 (겉표지)
     LocalData.sav   ← "내 PC의 로컬 데이터". 맵 탐색 시야가 여기 있다.
     WorldOption.sav ← 월드 설정
     Players\(UID).sav ← 각 플레이어 개인 데이터

2) 호스트는 항상 내부 UID "00000000000000000000000000000001" (=001) 이다.
   누가 그 세이브를 열든 그 사람이 001 이 된다.
   → 그래서 남의 세이브를 받아서 열면 "그 사람 캐릭터"로 플레이된다.
   → 내 캐릭터로 호스트하려면 내 캐릭터를 001 자리로 옮겨야 한다. (도구가 함)

3) 게스트 UID 는 스팀 계정마다 고정이다.
   단 **한 번 접속해서 캐릭터를 만들어야** 그 UID 가 세이브에 생긴다.

4) 맵 시야(안개)는 Level.sav 가 아니라 **각자 PC의 LocalData.sav** 에 있다.
   → 호스트가 바뀌면 "내 PC의 시야"가 그 월드와 안 맞아 검게 보일 수 있다.
   → 시야만 따로 이식하면 된다. (도구가 함)

■ 사용법 — 압축 푼 폴더의 PalworldHostChanger.bat 더블클릭
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
※ 반드시 팰월드를 완전히 끄고 실행. (켜져 있으면 도구가 막는다)
※ 백신 보호폴더(랜섬웨어 보호 등) 안에서는 실행이 막힌다. 바탕화면 등으로 옮겨서.
※ 설치·복원·시야 이식은 작업 전에 자동 백업을 만든다. 그래도 처음엔 직접 백업 권장.

┌ 기능 1. 호스트 변경 ─────────────────────────────┐
│ "누구든 원하는 사람을 호스트로" 만든다.                │
│                                                    │
│ 1. 기존 호스트에게 월드 폴더(32자리)를 통째로 받는다.   │
│ 2. [폴더 선택] → 받은 월드 폴더 선택                  │
│ 3. 캐릭터 목록에서 호스트로 만들 사람(보통 나) 클릭     │
│ 4. 둘 중 하나:                                      │
│    ★ 내 팰월드에 설치  = 내 PC에 바로 적용            │
│      (같은 월드가 있으면 _백업_날짜 로 보관)           │
│    전달용 폴더로 내보내기 = 남한테 줄 폴더 생성        │
│ 5. 게임 켜서 월드 선택창에 그 캐릭터 이름으로 뜨는지 확인│
│                                                    │
│ 팰·거점·길드·아이템 전부 따라간다.                    │
│ 원래 호스트 캐릭터는 게스트 자리로 옮겨진다.            │
└────────────────────────────────────────────────┘

┌ 기능 2. 게스트 캐릭터 복원 ───────────────────────┐
│ "친구가 접속했더니 캐릭터 생성창이 떴다" 해결.          │
│ (호스트를 바꾼 뒤 원래 호스트가 게스트로 들어올 때 등)   │
│                                                    │
│ 1. 그 친구가 캐릭터를 아무거나 만들고(Lv1) 1~2분 플레이 │
│    → 저장되게 한다. (이래야 UID 가 세이브에 박힌다)     │
│    ※ 캐릭터 생성창에서 끄면 UID 가 안 생겨서 소용없음   │
│ 2. 호스트가 게임 끄고 → 도구 실행 → [폴더 선택]        │
│    → 자기 SaveGames 안의 그 월드 폴더                  │
│ 3. [게스트 캐릭터 복원…]                             │
│    ① 되살릴 캐릭터 = 그 친구의 예전 캐릭터             │
│    ② 새로 접속한 캐릭터 = 방금 만든 Lv1               │
│ 4. 실행 → 그 친구 재접속하면 예전 캐릭으로 붙는다.      │
└────────────────────────────────────────────────┘

┌ 기능 3. 맵 시야 가져오기 ──────────────────────────┐
│ "맵이 다 검게 됐다" 해결. 캐릭터/팰/아이템 안 건드림.    │
│                                                    │
│ 1. 시야 많은 사람에게 LocalData.sav 를 받는다          │
│    (그 사람 세이브의 월드 폴더 안에 있음)              │
│ 2. 도구 실행 → [맵 시야 가져오기…]                    │
│    ① 가져올 시야 = 받은 LocalData.sav                 │
│    ② 적용할 내 것 = 내 세이브 월드 폴더의 LocalData.sav │
│    방식: 합치기(권장) / 덮어쓰기                       │
│ 3. 실행 → 게임 켜서 지도 확인                          │
│                                                    │
│ · 합치기 = 내 탐험 + 상대 탐험 둘 다 유지 (합집합)      │
│ · 덮어쓰기 = 상대 탐험으로 완전 교체                    │
│ · 호스트/게스트 상관없이 각자 PC에서 하면 된다           │
└────────────────────────────────────────────────┘

■ 전형적인 시나리오: "친구 월드를 내가 이어받기"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 기존 호스트에게 월드 폴더를 받는다.
2. 도구 실행 → [폴더 선택] → 나를 클릭 → [★ 내 팰월드에 설치]
3. 내가 호스트로 게임 시작. 친구들 접속.
4. 접속했는데 캐릭터 생성창이 뜬 친구 → 기능 2(게스트 캐릭터 복원)
5. 맵이 검은 사람 → 기능 3(맵 시야 가져오기)

전달용 폴더를 받은 사람은 이 도구로 설치해도 된다:
 [폴더 선택] → 받은 폴더 → 자기 캐릭터("현재 호스트") 클릭 → [★ 내 팰월드에 설치]
수동으로 하려면:
 탐색기 주소창에 %LOCALAPPDATA%\Pal\Saved\SaveGames 입력
 → 숫자 폴더 안에 월드 폴더를 그대로 넣기 (같은 이름이 있으면 이름 바꿔 백업)

■ 주의 / 문제 해결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
· co-op(초대 코드) 월드용이다. 전용 서버 이관 도구가 아니다.
· 믿을 수 있는 사람의 세이브만 열 것.
· 실행 전에 보안 경고가 뜨면 → [추가 정보] → [실행] (또는 [실행])
· 폴더 구성: runtime\ = 공식 파이썬(PSF 서명), app\ = 이 도구 소스(.py) 그대로.
  PyInstaller exe 는 윈도우 디펜더가 오탐(Wacatac!ml)해서 이렇게 배포한다.
· "액세스 거부" → 파일 우클릭 → 속성 → 아래 [차단 해제] 체크
· Steam 클라우드가 되돌릴 수 있으니, 처음엔 오프라인으로 켜보는 것을 권장.
· 잘못되면 _백업_ 폴더/파일을 원래 이름으로 되돌리면 된다.
